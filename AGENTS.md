# AGENTS.md

These are standing rules for anyone, human or agent, working on the 01 Capital website (www.01.capital).

The redesign brief, with the decisions made and those still open, is in [docs/BRIEF.md](docs/BRIEF.md). Check it before changing content. Settle open items with the site owner rather than guessing.

## Repo and commands

- The site is generated by `build.mjs` from `src/` into `dist/`, with no dependencies. See [README.md](README.md) for the layout, and [docs/DEPLOY.md](docs/DEPLOY.md) for hosting, Brevo and Turnstile.
- `npm run build` builds the site. `npm test` runs all checks. `npm run preview` serves `dist/` with a mock deck form.
- `dist/` is committed. After any change, rebuild and commit `dist/` too; a test fails if it's out of date. Never edit `dist/` by hand.
- `legacy/` is the previous site, kept for reference. Don't edit it.
- `portfolio.json` is the single source of truth for companies, and `src/data/site.json` for company facts.
- The live site can't be fetched from the agent sandbox, and npm packages can't be installed there. Keep the build dependency-free.

## Content

- Don't invent facts. That means no fund size, returns, deal counts, people, quotes, statistics or dates the owner hasn't supplied. Leave the field empty in `src/data/site.json`, and the section stays hidden.
- No market-making, price-support, market-cap or return claims anywhere. Don't advertise asset management, custody or trading for clients unless docs/BRIEF.md confirms 01 Capital is licensed for them.
- Companies:
  - Label a company `portfolio` only if 01 Capital invested in it.
  - Until the owner sets categories, the site shows every company under the neutral "Ecosystem" heading.
  - Never guess a company link. Use the old site, the owner, or a web search, and record which one in `url_source`.
- Articles carry the disclaimer from the template and must not name investments or give investment advice.

## Languages

- The site has four languages: English (`en`), Traditional Chinese (`zh-Hant`, at `/zh/`), Korean (`ko`) and Japanese (`ja`). English is the source; change it first, then update the other three.
- Every key in `src/locales/en.json` exists in every language file, with the same `{placeholders}`. Don't hard-code text in templates.
- Use standard codes in `lang` and `hreflang`, never `cn`, `kr` or `jp`.
- Translations are drafts until a native speaker has reviewed them.

## Secrets and forms

- Never commit `.env`, `.dev.vars`, API keys or other secrets. Document every setting in `.env.example`.
- The Brevo API key stays on the server, in Cloudflare settings. Never send it to the browser.

## Quality

- Don't block right-click, copying, text selection or zoom.
- Every image has alt text, and logos use the company name.
- Every page has one `h1`, a title, a meta description and a social preview image.
- Keep `npm test` passing.
